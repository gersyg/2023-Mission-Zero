#  Astro Pi: Mission Zero (2022–2023)

This is the code written by **John** and **George (me)** (**Team `gerjohn`**) from **2nd Gymnasium of Chaidari** for the European Astro Pi Challenge: **Mission Zero (2022–2023)**.

Astro Pi is an educational project run by the **Raspberry Pi Foundation** in collaboration with the **European Space Agency (ESA)**, giving students the opportunity to write Python code that runs on Raspberry Pi computers aboard the International Space Station (ISS).

##  ISS Flight Details

Our program achieved flight status and was executed aboard the International Space Station!

* **Execution Date & Time (UTC):** `2023-05-26` from `03:42:55` to `03:43:55`
* **ISS Coordinates:** `-16.6322, 113.8217` *(Over the Indian Ocean, off the northwestern coast of Australia)*

##  What the Code Does

1. **Ambient Light & Colour Sensing:** Uses the Astro Pi Mark II's colour and luminosity sensor (`sense.color`) to dynamically sample the ambient light inside the ISS and set the background colour of the 8×8 LED matrix in real time.
2. **Pac-Man Animation:** Runs a 3-frame animated Pac-Man loop chomping on white dots across the LED display for 28 seconds before clearing the screen.
